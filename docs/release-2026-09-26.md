# Ditto integration release, 2026-09-26

Historical release record for Ditto **0.1.1** and the original MFlow DSL/MIA implementation. Current MFlow uses 0.1.2 and native graph/loop search; see the [documentation index](README.md).

## Package publication

Ditto main commit `041562d`, tag `v0.1.1`, exposed general-purpose runtime checkpoint, branch, and budget capabilities without extra dependencies. Package validation included 458 tests, public-export checks, strict TypeScript usage, context/tools/state/budget/retrieval exercises, and both tarball and actual registry installation checks.

Registry propagation was allowed to complete before MFlow installed the release. MFlow did not substitute a checkout, private module, linked dependency, vendored runtime, or patched `node_modules`.

## Historical application integration

- Prefix reuse restores a completed explicit checkpoint at the first parent/child policy divergence. Task, model, pool, resource, runtime, and earlier-decision identities must match.
- Optional agent-turn caching uses public BranchStore with a 256-entry FIFO bound. A hit retains logical feasibility cost while actual new calls/tokens are zero. Factory and retrieval calls are not cached.
- Dual search/episode budgets reserve and settle the same provider usage. Missing/failed usage remains unknown and conservatively reserved.
- Continual state commits profiles, bounded procedural memory, provenance, and consolidation usage atomically. Bundles moved to version 2 and reject incompatible version-1 state.

MFlow's 23 tests and doctor checks passed against the registry-installed package. Those checks established engineering integration, not benchmark performance. No paid benchmark or multi-seed study was performed as part of that release.

## Limitations at release time

The request token upper bound remained a conservative heuristic. External-resource transactions were not implemented by recreating Ditto infrastructure. In-place search resumption was unavailable in the historical legacy search; the later default native AFlow path added resume support. Upstream AFlow source was kept external and unchanged.
