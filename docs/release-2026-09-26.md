## MFlow

`package.json` / lockfile 精确锁定 0.1.1。生产 import 检查禁止 Ditto 源码或私有路径。

- 默认 prefixCache：首个决策分歧前恢复；校验资源、模型、配置、任务、此前策略决策；只运行 suffix。
- 可选 agentCache：完整输入与资源版本作为 key，最多 256 项；只写成功结果；缓存命中保留逻辑用量，实际用量不重复收费。
- search 与 episode 共用 Ditto reservation/settlement；失败和无 usage 有保守实际账本；记录 run/branch/label。
- continual infer/evaluate：Ditto consolidation；profile、bounded memory、任务来源原子 commit；JSON snapshot 可跨进程恢复；无效 consolidation discard。standard 仍固定初始 pool。
- 旧 v1 bundle 拒绝加载，避免把旧执行语义误当成新协议。新 bundle version 为 2。

截至本记录创建时，`npm test` 的 23 项测试全部通过；`npm run mflow -- doctor` 已验证 registry 包的 Context、checkpoint、分支隔离和预算 API。后续 benchmark 和 DeepSeek 接入测试见仓库当前测试套件。

验收包括：数据划分、策略/MIA、晋升完整性、预算中断、真实 Ditto 工具调用、prefix/full 等价、后续分歧恢复、损坏/跨任务 checkpoint 拒绝、缓存失效、外部资源拒绝、并发预算、失败用量、canonical 恢复与回滚。

## 限制

- 真实模型、真实 benchmark、多 seed 消融尚未运行；这些需要模型配置与明确实验任务。
- 默认 token estimator 是保守启发式；物理硬上界与外部事务式资源仍按 ditto-requirements.md 跟踪。
- 当前保存执行 checkpoint 和搜索日志，不提供自动原地断点续搜；输出目录必须新建。
- MFlow 的参考基线来自上游 FoundationAgents/AFlow；实验性重写没有推送到上游。Ditto 发布改动已推送用户的仓库。
